# VoxCV

Voice-first CV studio. Build and update a résumé by talking, with a live preview and a chance to accept, reject, or undo every change.

The build specification is [`feature-list.md`](feature-list.md). Implementation progress lives in [`docs/IMPLEMENTATION_STATUS.md`](docs/IMPLEMENTATION_STATUS.md). Stack and product choices are in [`docs/DECISIONS.md`](docs/DECISIONS.md). The system shape is in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

Checkpoint 0 through Checkpoint 4 are done. Run `npm run db:migrate`, then `npm run dev`, and open http://localhost:3000.
